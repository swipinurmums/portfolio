# Aron Mobile-First Modelling Portfolio

Built from scratch around phone viewing.

- No horizontal page scrolling
- Equal left/right margins
- Mobile-first editorial layouts
- Tap images to enlarge
- Tap left/right to navigate
- Tap centre/outside to close
- Swipe left/right on mobile
- Image counter

Replace each Unsplash URL in `index.html` with your own local image path.
